# Installer reuse review — 2026-10-21

GitHub search checked jrsoftware/issrc (5,718 stars) and electron/windows-installer (1,635 stars). They supply general packaging rather than this pair of owned-game runtimes, official Minecraft profiles, Source BSP entity patch and approved voice reconstruction. Electron would also add a new Chromium runtime. Neither is adopted. The existing user-requested Doomcraft Eternal installer was inspected locally, including its package allowlist, SHA checks, isolated profile setup, settings backup, runtime validation and fixture tests. CraftLife reuses that approach with a small standard-library Python setup instead of adding a general installer framework.

The existing local CPython 3.12 runtime and Node 22.23.3 executable are packaged with their licenses and exact file hashes. No runtime download/install script runs on the player's machine. Python's standard library is allowlisted without site-packages/accounts; Node uses only built-in modules. Existing pinned Fabric Loader 0.19.5, Fabric API 0.161.0+26.3 and ReShade 6.8.0 remain unchanged. The official Launcher obtains Minecraft through its normal authenticated process.

For the two ADPCM voices, the local normalization algorithm follows libsndfile 1.2.2 `src/ms_adpcm.c` (1,725 stars checked today; commit `72f6af15e8f85157bd622ed45b979025828b7001`): mono block layout, predictor/adaptation, saturation and sample ordering. Reviewed the relevant decoder, WAV entry points, CMake dependency list and LGPL-2.1-or-later license at that tag. No libsndfile executable/library is loaded. The small derived Python module is supplied as LGPL-2.1-or-later source with the license. Exact input/decoded/output hashes and bounded reads are checked before overrides are installed. This is a targeted review of these paths, not a full dependency/security audit.

No full game assets, account files, saves, generated model weights or development logs enter the ZIP. Voice recipes consist of unchanged-byte references into locally owned WAV/PCM plus compressed edit spans, and are verified against all ten installed approved outputs. The ending BSP is prepared locally; only the entity-lump patcher is distributed. The six collision-model files are generated from this project's simple block SMD/QC, not a purchased Valve character.

References: https://github.com/jrsoftware/issrc , https://github.com/electron/windows-installer , https://github.com/libsndfile/libsndfile/tree/1.2.2 . General installer projects were evaluated for fit, not adopted or audited in full.
